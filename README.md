# Marvelous Designer专项训练网络班（第二期）

IT资源通道：jzit.top/26970/

作为早期的 MD 系统化实战课程，Marvelous Designer 专项训练网络班（第二期）以游戏角色服饰制作为核心目标，围绕软件核心功能搭建完整制版与布料模拟链路，重点面向 CG、次世代角色方向学习者，打下扎实的数字服装生产基础，帮助学员摆脱只会简单拼接裁片的入门阶段，掌握项目可用的服装资产制作能力。

课程开篇从 2D 版型基础功能入手，建立制版思维。不同于直接上手模拟布料的速成教学，课程优先讲解裁片绘制、曲线编辑、省道、分割片、对称制版等基础功能，让学员理解服装版型逻辑。课程着重训练缝合、固定针、折叠、收褶等基础操作，区分上衣、裤子、基础外套的版型结构，规范裁片排布与缝合顺序，解决新手最常见的版型歪斜、缝合错位、结构不符合真实服装工艺的问题。这一阶段的核心目标，是让学员看懂服装结构，能够根据参考图独立拆解裁片，而不是单纯依靠模板。

布料物理调节是课程核心模块，聚焦面料参数与模拟控制功能。课程详解不同面料的物理属性调节，包括拉伸刚度、弯曲刚度、摩擦力、密度等参数，分别调试牛仔、棉布、丝绸、冲锋衣面料的质感差异。针对模拟卡顿、布料穿插、褶皱僵硬等高频问题，讲解冻结、碰撞层、厚度设置、子网格精度等功能的搭配方案，学会控制重力、局部收缩，手工引导褶皱走向。课程不追求花哨特效，优先保证静态模拟稳定，褶皱分布自然，适合游戏角色静帧展示，是项目资产制作的基础。

角色适配与多层穿搭功能，是这期课程重点打磨的实战内容。课程讲解模特导入、体型适配、姿态固定、弹性收缩等功能，学习服装贴合人体的调节思路，处理紧身服饰、宽松外袍、防弹衣等不同类型装备。多层叠穿是本期重点难点，教学员合理设置裁片层级、碰撞对象，处理内搭、外套、配饰之间的碰撞关系，减少多层布料互相穿透。同时讲解固定点、钉针的灵活使用，在不破坏版型的前提下锁定关键位置，让服装在指定姿态下稳定成型。

在资产导出与软件联动模块，课程围绕 UV、贴图烘焙、格式导出功能展开。课程重点讲解 MD 内部 UV 拆分、布料厚度烘焙、法线贴图导出流程，输出适配 Blender、Maya、八猴等 CG 软件的资产。课程偏向静态服装资产交付，以游戏角色高模服装为主要产出方向，把 MD 做好的服装模型导入后续软件做材质、细节雕刻与渲染。同时讲解缓存基础导出功能，简单了解布料动画的基础流程，为后续进阶动画布料学习预留空间。

整套课程以多个次世代案例串联训练，涵盖日常休闲服饰、机能战术装备、古风汉服等主流 CG 角色服装类型，案例选择贴合当时游戏行业角色制作需求。相比后续迭代版本，第二期更侧重基础流程的稳固落地，优先保证版型、模拟、导出的标准化，适合零基础或者 MD 入门后一直做不出项目级服装的学员。课程的价值，是把 MD 从一个 “布料玩具” 变成标准化的 CG 资产生产工具，让学员建立规范的制版、调参、碰撞、导出工作流，能够独立交付可直接进入角色项目使用的数字服装，为后续学习动态布料、高精度虚拟时装打下根基。
